# 整经数据口径修正 与 工艺流程图（整经 / 织造 / 水洗）

> 本说明对应收到反馈后对「整经」口径的更正，以及甘特图按三大工艺流程展示的改造。
> **不进入人工拖动、滚动重排**，只做数据口径修正与按流程的只读甘特图视图。

## 一、整经数据口径更正

原实现的错误：把「整经计划」上半部分设备列标注为「织机」的 60 行（30 台织机 × 轴个数/上轴
两行）当成 60 个整经任务，并把「织机」当作整经机。

更正如下：

| 口径 | 说明 |
|---|---|
| 上半部分「织机」列 | 经轴将要安装的【目标织机】，不是整经机 |
| 上半部分约 60 行 | 是 30 台织机对应的 轴个数/上轴 两类指标，不能当成 60 个整经任务 |
| 经轴品番 WP550 / WN453 | 整经产出的【经轴规格 SKU】，也是织造投入物 |
| 织造品番 RP550 / RN453 | 织造完成后的【半成品 SKU】，也是水洗投入物 |
| 整经机编号 | 源表【没有整经机编号】，不得用目标织机号代替，不得虚构 |
| 经轴库存 | 前日库存 + 当日整经完成量 - 当日织造上轴需求 |

### 整经任务来源（更正后）
从「整经计划」下半部分（经轴库存推移）与「整经预测辅助表」提取，重点读取：
经轴品番、设定米数、整经根数、钢筘、使用纱线、整经计划米数、整经个数、初始库存、库存推移。
整经任务 = 每个经轴品番 × 有整经计划的日期。

### 数据模型拆分
```
warp_beam_sku        经轴品番(SKU)
beam_instance_id     实体经轴编号(源表缺失→生成虚拟编号，标记为推导数据)
target_loom_id       目标织机
warping_machine_id   整经机编号(当前为空 + 待补充)
weaving_sku          织造品番(半成品)
washing_sku          水洗品番
```

> 多产品可共用同一经轴品番（如 WP551 对应 PH54513B / PH545140 / PH555140），
> 因此不能按产品简单生成一根经轴。

## 二、工艺流程关系

```
产品需求 → 纱线准备 → 整经生成经轴 → 经轴上目标织机 → 织造生成织造品番 → 水洗
```

示例：`PH54512B → WP550 → RP550 → SP550`（经轴品番 → 织造品番 → 水洗品番）。

## 三、甘特图调整

1. 甘特图按【整经 / 织造 / 水洗】分组展示，不再只按织机。
2. 同一产品/任务能看到三道工序的前后衔接关系。
3. 整经条：经轴品番、计划米数、轴数、目标织机、数据来源。
4. 织造条：织机编号、经轴品番、织造品番、数量、起止时间。
5. 水洗条：水洗设备编号、水洗品番、数量、起止时间。
6. 顺序约束：整经完成才能上轴织造、织造完成才能进入水洗。
7. 整经机编号缺失时：整经条以「整经计划池 / 整经能力」展示，不伪造具体设备。
8. 虚拟经轴、推导时间、缺失设备在页面上明确标识（「推导」标记）.
9. 保留「按织机」查看，新增「按工艺流程」，默认进入工艺流程视图。

### 3) 时间来源说明

三道工序中只有【织造】时间是 CP-SAT 真实求解结果；【整经】与【水洗】时间为来源表计划
（展示用），属于推导/展示时间，**不是 CP-SAT 约束结果**。整经/水洗的起止时间仅用于展示前后衔接，
不作为 CP-SAT 已排或已约束的依据。接口与页面在整经/水洗条上标注 `time_source=来源表计划(非CP-SAT约束)`，
织造条标注 `time_source=CP-SAT求解结果`。

### 4) 三道工序 flow_id 串联 + 缺水洗品番停在织造节点

- 每条工艺链路带唯一 `flow_id`（`FLOW-{产品}`），整经/织造/水洗条之间用 `flow_id` 关联。
- 缺水洗品番的产品（PH55463N）**停在织造节点**，织造条标注 `missing_washing=True` 与原因
  “缺水洗品番(水洗名称为空)，工艺串联在织造节点终止”，**不直接隐藏**。

### 5) 经轴库存递推校验

公式：`库存(当日) = 前日库存 + 当日整经完成量 - 当日织造上轴需求(米)`。

非零样例（WP550，逐日复算，已验证与源表 库存 行一致）：

| 日期 | 前日库存 | 整经完成量 | 织造上轴需求 | 复算库存 | 源表库存 |
|---|---|---|---|---|---|
| 2026-06-16 | 14400 | 9660 | 4687.5 | 19372.5 | 19372.5 |

> 说明：06-16 满足递推式（14400 + 9660 - 4687.5 = 19372.5）。个别日期源表「整经计划」行与
> 「库存」行存在一天列偏移（如 06-15/06-17/06-18），属源表内部口径差异，已在报告明细 `match=False` 标注。
