# 织造滚动排产模拟（第一版）

本模拟将现有 CP-SAT 织造排程结果进一步展开为可执行事件，用于先验证业务流程，再决定
哪些规则需要正式进入优化模型。

## 已实现流程

1. CP-SAT 生成织造任务的机台、顺序和计划起止时间。
2. 按机台实时状态把每个任务拆成经轴段。
3. 判定四种准备方式：
   - 线边余轴直接续产；
   - 同品番接经；
   - 原品番仕挂；
   - 改品番仕挂（含穿综穿筘）。
4. 新经轴先安排整经；改品番时再安排穿综穿筘。
5. 经轴须在上机前 2 小时准备完成，不满足时自动后移织造开始时间。
6. 设备故障/维修窗口不可排产。
7. 输出未来 24 小时、48 小时的产量、机台状态和延期风险。
8. 自动校验机台独占、整经资源独占、穿综穿筘资源独占、备轴提前期及数量对账。

## 运行

在项目根目录 `D:\dsh\cp_sat_demo` 执行：

```powershell
python -m weaving_demo.run_simulation
```

加入 L-03 的模拟故障窗口：

```powershell
python -m weaving_demo.run_simulation --with-fault
```

指定输出文件和求解时限：

```powershell
python -m weaving_demo.run_simulation `
  --with-fault `
  --max-time 8 `
  --out weaving_demo\sample_data\simulation_result.json
```

## 输出结构

`sample_data/simulation_result.json` 的主要字段：

- `weaving_plan`：织造经轴段计划；
- `loom_setup_plan`：接经、原品番仕挂、改品番仕挂计划；
- `threading_plan`：穿综穿筘计划；
- `warping_plan`：整经计划；
- `forecasts`：未来 24/48 小时工况；
- `kpi`：产量、完成时间、准备方式次数、延期等指标；
- `issues`：因准备资源、提前期或停机造成的后移说明；
- `validation`：资源重叠、提前期和数量对账校验；
- `solver`：原始 CP-SAT 求解结果，便于对照。

| 参数 | 当前值 |

| 经轴上机前准备提前期 | 120 分钟 |
| 边撑使用次数上限 | 5 次 |
| 缺省经轴长度 | 3600 米 |
| 单只经轴整经时间 | 240 分钟 |
| 穿综穿筘时间 | 480 分钟 |
| 接经占机时间 | 120 分钟 |
| 原品番仕挂占机时间 | 390 分钟 |
| 改品番仕挂占机时间 | 340 分钟 |

## 下一步建议

1. 用现场数据补充每台织机的在机经轴、剩余米数、边撑累计次数。
2. 确认四类准备方式的标准工时，以及整经机和穿综穿筘工位的实际数量/班次。
3. 用真实周计划替换演示任务，进行历史一天回放并与人工计划比较。
4. 规则确认后，将四类准备方式和前工序资源直接纳入 CP-SAT，而不是仅在求解后模拟。
5. 再实现事件到达时的冻结区、未完成量计算和滚动重求解 API。
