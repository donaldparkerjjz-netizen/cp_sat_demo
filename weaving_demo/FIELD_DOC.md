# 整经织造排工排产 Demo · 字段说明文档（阶段1）

> 本文件说明 `weaving_demo/model.py` 中领域模型各字段的来源、中文业务含义、
> 类型与示例。数据由 `extract.py` 从益丰生产管理表单 Excel 清洗映射而来。

## 1. 全局设置 `Settings`

| 字段 | 业务含义 | 来源 | 类型 | 示例 |
|---|---|---|---|---|
| 当前日期 | 数据当前日期（计划基准日） | 织造计划表头“当前日期” | str | `2026-05-18` |
| 数据节点 | 节点备注 | 织造计划表头 | str | `整经织造益丰生产管理表单` |
| 卷曲率 | 经纱卷曲率 | 整经计划表头 | float | `0.08` |
| 休日 | 休息日（星期几，7=周日） | 织造计划“休”标记 | list[int] | `[7]` |
| 排程起点 / 排程终点 | 规划期起止 | 配置 | str | `2026-04-01` / `2026-08-31` |

| 客户 | 客户简称（AB/TG/YFSS…） | - | `AB` |

| 使用纱线 | 经纱纱线代码 | - | `LS7056AB` |
| 整经设定长度 | 每卷整经设定长度 | 米/卷 | `3600` |
| 织造效率 | 织机日产能 | 米/天 | `400` |

> “KG/米”两列，需按单位行区分；`extract.py` 已按单位行自动区分映射。
> 钢筘型号目前在 `工艺汇总背番号` 中（较复杂，阶段1暂未解析，列为数据缺口）。

## 3. 织机 `Loom`

来源：`②织机状态`（区域1~9）。能力列即工装条件。

| 字段 | 业务含义 | 类型 | 示例 |

| 目前对应产品 | 当前对应产品 | str | `PH555120` |
| 产能设定 | 织机日产能（由织造计划回填） | float | `400` |
| 废边盘 | 是否具备废边盘 | bool | `true` |
| 废边盘安装孔位 | 废边盘安装孔位 | str | `1` |
| 切边 | 是否可切边 | bool | `true` |
| 大卷装 | 是否大卷装 | bool | `true` |
| 水过滤 | 是否水过滤 | bool | `true` |
| 纱架 | 是否具备纱架（经轴架） | bool | `true` |
| 钢筘 | 钢筘（如 9.3钢筘） | str | `9.3钢筘` |

## 10. 交期 `DueDate`

来源：`估算 260428`（转置布局：月份在列）。阶段1由“客户月度预测”按月份推导。

| 字段 | 业务含义 | 示例 |
|---|---|---|
| 产品款号 | 产品（预测汇总用） | `TG PET 5551 SR 2.2米幅宽` |
| 月份 | 预测月份 | `2026-05` |
| 预测数量 | 该月客户预测（米） | `15000` |
| 来源 | 交期来源 | `customer_monthly_forecast` |

> 交期规则见 `config.py` 的 `due_date_params`：`due_source=customer_monthly_forecast`，
> `due_by_month_end=True`（每月末作为交期）。

### 附：业务规则参数入口

所有关键业务规则集中在 `weaving_demo/config.py`：
`HARD_RULES`（产品-机台适配/织机独占/经轴独占/上轴先于织造/物料非负/锁定任务/工装条件）、
`OBJECTIVE_PRIORITY`（先降交期延误→再减换款换轴→再减计划变动）、
`OBJECTIVE_WEIGHTS`、`CHANGEOVER_PENALTY`、`TIME_PARAMS`、`CAPACITY_PARAMS`、
`DUE_DATE_PARAMS`、`MATERIAL_PARAMS`。
